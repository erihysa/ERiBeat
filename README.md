ERiBeat 🎵

ERiBeat is a music app project built with Flutter for Android.

Features

- Search for music videos on YouTube
- Display video titles and search results
- Music playback integration
- Dark theme interface

Build APK

The Android APK is built using GitHub Actions.

1. Open the Actions tab.
2. Select Build Flutter APK.
3. Open a successful workflow run.
4. Download the "app-release" artifact.

Important

YouTube playback and background playback depend on the supported player integration and applicable YouTube policies.
